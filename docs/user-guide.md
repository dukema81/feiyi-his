# 飞医医疗管理系统使用手册

版本：v1.0 ｜ 适用对象：全部角色

## 1. 系统定位

飞医医疗管理系统（FeiYi HIS）面向中小型门诊/诊所/体检机构，覆盖「排班 → 挂号 → 叫号 → 病历 → 处方 → 收费 → 发药 → 库存 → 风险」门诊全流程，并提供 REST API 供医保、LIS、企业 OA/ERP 等外部系统对接。

## 3. 页面说明（14 页）

1. **工作台**：今日挂号/接诊/处方/收入 KPI、待发药、候诊、低库存、临期、未处理风险，候诊队列速览与快捷入口。
2. **患者管理**：建档（姓名/性别/出生/过敏史/医保类型与号）、按姓名/档案号/手机号搜索、查看就诊史（病历+处方聚合）。
3. **医生管理**：医生档案（科室/职称/挂号费/专长）。
4. **排班管理**：按医生×日期×时段排班并设号源；同医生同时段重复自动拒绝。
5. **门诊挂号**：选患者+排班挂号，生成 GH 号，收挂号费；候诊队列叫号（waiting→called→in_consult→done），可退号释放号源。
6. **门诊病历**：主诉/现病史/诊断/处理意见；一挂号单一病历，完成接诊自动建空病历。
7. **处方管理**：多明细开方（药品/剂量/用法/天数/数量），金额自动 Decimal 累计；剂量超限自动登记风险；draft→submitted→dispensed。
8. **收费结算**：合并挂号费+处方费，按患者医保类型自动折扣（职工 85% / 居民 65% / 自费 100%），支持现金/微信/支付宝/医保，支持退费。
9. **药房发药**：待发药列表一键发药，按效期近先出（FEFO）扣批次库存，生成发药记录。
10. **药品库存**：批次库存、效期、安全库存；低库存/临期标红。
11. **供应商**：供应商档案与应付余额。
12. **财务流水**：今日收入/退款/单量汇总与全部流水。
13. **风险预警**：药品低库存、效期预警、剂量超限、挂号超时四类扫描与处理。
14. **系统管理**：用户、公告、API Key（对接外部系统，仅显示一次）、增量同步状态。

## 4. 开一次门诊五步上手

1. 排班：在「排班管理」为医生设置今日号源；
2. 挂号：在「门诊挂号」为患者挂号并打印 GH 号，候诊叫号；
3. 病历与处方：接诊完成后在「门诊病历」记录诊断，在「处方管理」开方并提交；
4. 收费：在「收费结算」合并挂号费与处方费收款；
5. 发药：药师在「药房发药」执行发药，库存自动扣减。

## 5. 金额口径

系统内所有金额以「分」存储（字段名 *_cents），界面显示自动换算为元。医保折扣对总额一次量化到分（HALF_UP），杜绝累计误差。

## 6. 外部系统对接

- 接口契约见《飞医医疗管理系统 REST 接口契约》（api.md）。
- 推荐 ApiKey 通道：系统管理 → 生成 Key → 请求头 `X-Api-Key`。
- 增量同步：`GET /api/sync?since=<版本>&entities=patients,...`，适合与集团 ERP/OA 定期对账。

## 7. 部署运维

- 启动：`python backend/server.py`（环境变量 HIS_PORT 默认 8028、HIS_DB 默认 ../data/feiyi.db）。
- 生产：systemd 守护 + nginx `/his/` 前缀反代。
- 备份：每日备份 data/feiyi.db（WAL 模式，建议停写窗口或用 sqlite3 backup）。

## 8. FAQ

- **挂号提示余号不足**：排班号源已满，换时段或加号源。
- **发药提示库存不足**：先在采购管理入库对应批次。
- **处方重复收费 409**：该处方已在其他收费单中，核实后走退费流程。
- **医生排班冲突 422**：同医生同时段已有排班，可修改既有排班。
